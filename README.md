## Language Identification System using NLP 🌐

This project uses Natural Language Processing (NLP) and Python to automatically identify the language of a given text. Using the `langdetect` library, it can recognize multiple languages, including English, Kannada, Hindi, Tamil, Telugu, French, Spanish, and many more.

**Technologies:** Python, NLP, langdetect

**Features:**
- Automatic language detection
- Supports multiple languages
- Displays the detected language and language code

**Platform:** Google Colab / Jupyter Notebook
